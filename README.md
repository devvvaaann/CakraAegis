# CakraAegis: AI-Driven Live Screen-Aware Cyber Security Assistant

## Deskripsi Singkat
CakraAegis adalah asisten siber cerdas berbasis AI yang dirancang untuk mengamankan aplikasi web secara *real-time*. Memiliki kemampuan *live screen-aware* untuk mendeteksi kerentanan berbasis standar OWASP Top 10, menilai tingkat urgensi, serta memberikan rekomendasi perbaikan kode secara instan.

Gunakan API Key pribadi dari Google AI Studio untuk menggunakan CakraAegis
