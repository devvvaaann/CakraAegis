RINGKAS: Terdeteksi percobaan serangan Command Injection dengan tingkat bahaya tinggi. Kode terkait tidak tersedia, jadi saya belum bisa memastikan apakah server Komandan rentan.

Serangan ini berpotensi berhasil jika aplikasi mengeksekusi input pengguna langsung ke perintah shell tanpa sanitasi. Karena kode tidak ada, saya tidak dapat menunjuk baris yang spesifik.

Berikut contoh pola perbaikan umum jika ada fungsi eksekusi shell pada kode Anda:

```python
# SEBELUM (Rentan)
import os
os.system("ping " + user_input)

# SESUDAH (Aman)
import subprocess
subprocess.run(["ping", "-c", "1", user_input], check=True)
```

Langkah respons cepat yang perlu Komandan lakukan:
1. **Blokir IP & Rate Limit:** Blokir IP sumber serangan di firewall (iptables/NFW) dan aktifkan rate limiting pada endpoint terkait.
2. **Aturan WAF:** Pasang aturan WAF untuk memblokir karakter berbahaya seperti `;`, `&&`, `|`, dan `$()`.
3. **Audit Log:** Periksa log aplikasi untuk melihat apakah ada respon perintah shell yang berhasil dieksekusi.
