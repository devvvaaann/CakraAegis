RINGKAS: Terdeteksi serangan SQL Injection terdistribusi tingkat tinggi pada endpoint login, Bos. Berpotensi berhasil karena server merespons HTTP 200, tapi kode backend login belum disertakan di sini.

### 2. Penilaian Potensi & Analisis
* **Potensi Keberhasilan:** **Tinggi/Kritis**. Server mengembalikan status `HTTP 200` dengan ukuran respons identik (512 bytes) terhadap payload bypass autentikasi (`1' OR 1=1--`).
* **File/Fungsi:** Target berada di `/login.php` parameter `id`. Kode `prompts.py` yang dilampirkan tidak terkait langsung (itu hanya prompt AI). Kode backend `login.php` diperlukan untuk verifikasi pasti.

### 3. Kode Perbaikan (Prediksi Kerentanan di `login.php`)

```php
// SEBELUM (Rentan SQLi):
$id = $_GET['id'];
$query = "SELECT * FROM users WHERE id = '$id'";
$result = mysqli_query($conn, $query);

// SESUDAH (Gunakan Prepared Statements & Tipe Data Ketat):
$id = filter_input(INPUT_GET, 'id', FILTER_VALIDATE_INT);

if ($id === false) {
    http_response_code(400);
    exit("ID tidak valid.");
}

$stmt = $conn->prepare("SELECT id, username, role FROM users WHERE id = ?");
$stmt->bind_param("i", $id);
$stmt->execute();
$result = $stmt->get_result();
```

### 4. Respons Cepat
1. **Blokir IP Attacker (iptables/firewall):**
   ```bash
   sudo iptables -A INPUT -s 203.0.113.203,203.0.113.198,203.0.113.242,203.0.113.209,203.0.113.22,203.0.113.207 -j DROP
   ```
2. **Aturan WAF (ModSecurity / Nginx):**
   Blokir karakter kutip dan komentar SQL di query string URL login:
   ```nginx
   if ($query_string ~* "(\'|--|union|select|or%201=1)") {
       return 403;
   }
   ```
3. **Rate Limiting:** Terapkan pembatasan request ketat untuk endpoint `/login.php` (maksimal 5 req/menit per IP).
4. **Audit Akun:** Cek log database segera untuk melihat apakah ada user admin yang berhasil login otomatis dari IP tersebut.
