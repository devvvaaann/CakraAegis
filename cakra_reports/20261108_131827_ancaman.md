RINGKAS: Terdeteksi upaya *Command Injection* berisiko tinggi. Namun, potensi keberhasilan belum bisa dipastikan karena kode sumber terkait tidak ditemukan dalam log.

Mohon berikan berkas atau fungsi kode yang menangani input tersebut agar saya bisa menganalisis celah rentannya secara akurat.

Berikut langkah mitigasi darurat yang Komandan bisa terapkan sekarang:

1. **Blokir IP & Aturan WAF:**
   Tambahkan aturan WAF/Nginx untuk memblokir IP penyerang dan menolak karakter berbahaya seperti `$(`, `;`, `&&`, atau `|` pada parameter request.
   ```nginx
   # Contoh blokir karakter eksekusi perintah di Nginx
   if ($args ~* "(;|\||\$|\`|>|<)") {
       return 403;
   }
   ```

2. **Mitigasi Kode Umum (Prinsip Perbaikan):**
   Jangan pernah mengeksekusi perintah shell langsung dari input pengguna. Gunakan fungsi aman dengan parameter terpisah.

   *Sebelum (Rentan):*
   ```python
   import os

   # Berbahaya: input di-concatenation langsung ke shell
   os.system("ping -c 1 " + user_input)
   ```

   *Sesudah (Aman):*
   ```python
   import subprocess

   # Aman: argumen dipisah sebagai list dan shell=False
   subprocess.run(["ping", "-c", "1", user_input], shell=False, check=True)
   ```
